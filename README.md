# Stackan - M5Stack お買い物ごっこゲーム -

M5StackのM5GOとQRコードスキャナユニット(STM32F030)を使用した、子供向けのお買い物ごっこ用おもちゃです。QRコードを紙に印刷してスキャンすると、M5Stackの画面に「品名」「イラスト」「金額」が表示されます。複数の商品を買い物かごに追加し、合計金額の計算や会計も楽しめます。

## 機能

- QRコードスキャンによる商品認識
- カラフルなイラスト表示
- 買い物かご機能（複数商品の管理）
- ページング付き買い物かご表示
- 会計機能（合計金額の計算）
- サウンドフィードバック（成功/エラー音）
- 直感的なボタン操作

## 必要なハードウェア

- M5Stack Basic または M5GO
- QRコードスキャナユニット（STM32F030）
- 印刷したQRコード（商品カード）

## 必要なソフトウェア

- [PlatformIO](https://platformio.org/)
- Arduino Framework
- 依存ライブラリ:
  - M5Stack (0.4.6以上)
  - M5GFX (0.2.6以上)

## インストール方法

1. [PlatformIO IDE](https://platformio.org/platformio-ide)をインストール
2. このリポジトリをクローンまたはダウンロード
3. PlatformIOでプロジェクトを開く
4. M5Stackを接続し、ビルド・アップロード

## 使用方法

### QRコードの作成

以下の形式のQRコードを作成して印刷します：
- `product:0` → りんご (100円)
- `product:1` → バナナ (150円)
- `product:2` → ぎゅうにゅう (200円)

QRコード作成は、無料のオンラインQRコード生成サービスを利用できます。

### 商品をスキャンする

1. M5Stackの電源を入れると初期画面が表示されます
2. QRコードスキャナでQRコードを読み取ります
3. 商品の情報（名前、金額、イラスト）が表示されます

### ボタン操作

- **ボタンA（左）**
  - 初期画面に戻る・リセット
  - 会計画面から買い物を続ける
  
- **ボタンB（中央）**
  - 商品表示中：カートに追加
  - 初期画面中：買い物かごを表示
  - 買い物かご表示中：前のページへ
  - 会計画面中：カートをクリア

- **ボタンC（右）**
  - 商品表示中：会計へ進む
  - 買い物かご表示中：次のページ/会計へ
  - 会計画面中：買い物終了（リセット）

- `src/QrScanner.cpp`: QRコードスキャナ制御
- `src/ShoppingCart.cpp`: 買い物かご機能
- `src/UI.cpp`: ユーザーインターフェース
- `include/Product.h`: 商品データ構造体と管理クラス

- `include/UI.h`: UI管理クラス
- `include/Images.h`: 商品イラストデータ

## カスタマイズ方法

### 商品の追加

`Product.cpp`の`ProductDB::init()`メソッド内に新しい商品を追加できます：

```cpp
// 商品データの設定
products[0] = {"0", "りんご", 100, APPLE_IMG, 32, 32};
products[1] = {"1", "バナナ", 150, BANANA_IMG, 32, 32};
products[2] = {"2", "ぎゅうにゅう", 200, MILK_IMG, 32, 32};
// 新しい商品を追加
products[3] = {"3", "おかし", 80, SNACK_IMG, 32, 32};
```

商品イラストは`Images.h`に追加し、32x32ピクセルサイズの16bitカラーデータとして定義します。

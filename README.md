# Stackan - M5Stack お買い物ごっこゲーム -

M5Stack Basic / M5GO と QRコードスキャナユニット(STM32F030)を使った、4歳児向けのお買い物ごっこアプリです。商品カードのQRコードをスキャンすると、商品がすぐに買い物かごへ入り、画面に商品名・金額・合計が表示されます。

## 体験設計

- 子どもは商品カードを「ピッ」とスキャンするだけ
- スキャンした商品は自動で買い物かごに追加
- 画面には大きな商品表示、合計金額、個数を表示
- ボタンCで会計し、「おかいけいできた」を表示
- エラーコードや配線診断は画面に出さず、Serialログに出力

## 必要なハードウェア

- M5Stack Basic または M5GO
- QRコードスキャナユニット（STM32F030）
- 印刷したQRコード付きの商品カード

## 必要なソフトウェア

- PlatformIO
- Arduino Framework
- 依存ライブラリ:
  - M5Stack 0.4.6以上
  - M5GFX 0.2.6以上

## インストール

1. PlatformIO IDE または PlatformIO CLI をインストール
2. このプロジェクトを開く
3. M5Stackを接続する
4. `m5stack-core-esp32` 環境でビルド・アップロード

## QRコード

QRコードは以下の形式で作成します。

- `product:0` -> りんご 100円
- `product:1` -> バナナ 150円
- `product:2` -> ぎゅうにゅう 200円
- `product:3` -> パン 120円
- `product:4` -> たまご 180円
- `product:5` -> にんじん 90円
- `product:6` -> おにぎり 130円
- `product:7` -> ジュース 160円
- `product:8` -> もも 80円
- `product:9` -> アイスクリーム 140円
- `product:10` -> さかな 220円
- `product:11` -> 鶏肉 260円

同じカードを短時間に連続で読んだ場合は、二重登録を防ぐため無視します。

### QRコードスキャナ接続時の注意

QRコードスキャナユニットをM5StackのPort Cに接続する場合は、ユニット側面の通信切替スイッチを **UART側** にしてください。スイッチがI2C側のままだと、スキャナ本体は「ピッ」と鳴って読み取り成功に見えても、M5Stack側には読み取り結果が届かずカートが更新されません。

## 遊び方

1. 電源を入れると「ピッとしてね」と表示されます
2. 商品カードのQRコードをスキャンします
3. 商品が自動で買い物かごに入ります
4. 続けて商品をスキャンできます
5. ボタンCで会計します

## ボタン操作

- ボタンA（左）
  - いつでも最初の画面に戻る
  - 会計画面ではカートを空にして次のお買い物へ

- ボタンB（中央）
  - 買い物かごを表示
  - 買い物かご画面では次ページへ

- ボタンC（右）
  - 会計画面へ
  - 会計画面ではカートを空にして次のお買い物へ

## ファイル構成

- `src/main.cpp`: アプリ状態、ボタン、QRスキャン処理
- `src/Product.cpp`: 静的商品カタログ
- `src/ShoppingCart.cpp`: 固定長の買い物かご
- `src/QrScanner.cpp`: QRコードスキャナ制御
- `src/ScanDeduplicator.cpp`: 短時間の重複スキャン防止
- `src/UI.cpp`: 320x240向け画面描画

## 商品の追加

商品は `src/Product.cpp` の `PRODUCTS` 配列に追加します。

```cpp
static Product PRODUCTS[] = {
  {"0", "りんご", "APPLE", 100, TFT_RED, 'A'},
  {"1", "バナナ", "BANANA", 150, TFT_YELLOW, 'B'},
  {"2", "ぎゅうにゅう", "MILK", 200, TFT_WHITE, 'M'},
  {"3", "パン", "BREAD", 120, 0xF5B6, 'P'},
  {"4", "たまご", "EGG", 180, 0xFFE0, 'E'},
  {"5", "にんじん", "CARROT", 90, 0xFC60, 'C'},
  {"6", "おにぎり", "RICE", 130, 0xFFFF, 'R'},
  {"7", "ジュース", "JUICE", 160, 0xF81F, 'J'},
  {"8", "もも", "PEACH", 80, 0xFDB8, 'P'},
  {"9", "アイスクリーム", "ICE CREAM", 140, 0xAEDC, 'I'},
  {"10", "さかな", "FISH", 220, 0x07FF, 'F'},
  {"11", "鶏肉", "CHICKEN", 260, 0xFBE0, 'C'},
};
```

QRコードは追加したIDに合わせて `product:11` のように作成します。

## テスト

PlatformIO CLI が使える環境で実行します。

```sh
pio test -e m5stack-core-esp32-tests
```

この環境では `pio` コマンドが未インストールの場合があります。その場合はPlatformIO IDEから同じテスト環境を実行してください。
